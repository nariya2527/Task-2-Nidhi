# Fake Job Data Preprocessing

This project is based on cleaning and preprocessing a fake job posting dataset using Python.

In this project, I handled missing values, removed duplicate records and cleaned different columns to improve the quality of the dataset.

I also performed basic analysis and visualization to understand fake and real job postings.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Tasks Performed
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Text Preprocessing
- Basic Data Visualization

## Output
The final cleaned dataset was saved as:
cleaned_fake_jobs.csv
